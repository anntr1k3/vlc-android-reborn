## ⚡ Ключевые улучшения в версии Reborn

### 🖤 1. Минималистичный дизайн и режим True AMOLED Black
* **Чистый черный цвет (`#000000`)**: В темной теме пиксели на экранах OLED/AMOLED полностью выключаются. Это дает бесконечный контраст, исключает серое свечение в темноте и существенно экономит заряд батареи.
* **Никакого визуального шума**: Удалены устаревшие псевдо-градиенты и наложения (`deep_space_gradient`, `top_gradient`, `bottom_gradient`) — интерфейс переведен на лаконичные матовые поверхности Material 3.
* **Современная типографика**: Четкий и легкочитаемый шрифт `sans-serif-medium` для заголовков видео, таймеров плеера, названий треков, полос эквалайзера и виджетов.

### 🚀 2. Производительность и плавность 120 FPS
* **Анимация мини-плеера без перерисовки лейаута**: Пока шторка едет, бар анимируется GPU-трансформациями (`scaleY`/`alpha`); в полностью раскрытом состоянии бар скрывается через `View.GONE`, чтобы header не висел на пустых 4dp.
* **Мгновенная отмена устаревших задач (`ImageLoader`)**: При быстром скролле списков фоновая загрузка обложек для ушедших с экрана карточек немедленно отменяется, предотвращая лаги и перегрев CPU.
* **Мгновенный поиск с Debounce**: Задержка в 150мс при наборе текста защищает базу данных SQLite от блокировок и очередей параллельных запросов на каждый символ.
* **Пакетная пред-аллокация памяти**: Исключены лишние переаллокации списков в `MedialibraryProvider`, что исключает паузы сборщика мусора при загрузке огромных плейлистов (10 000+ треков).

### 🔋 3. Энергоэффективность и фоновая работа
* **Адаптивный таймер сна**: Вместо ежесекундного цикла — задержка до 30 с, пока до срабатывания далеко, и точное оставшееся время на последнем тике.
* **Оптимизация корутин**: Трассировка корутин изолирована в Debug-сборках, убирая микрозадержки при вызовах `suspend` в релизе.

### 👆 4. Удобство и эргономика управления
* **Порядок в Настройках**: Все параметры аккуратно распределены по 4 разделам (Воспроизведение, Медиатека, Устройства и безопасность, Система) без дублирования.
* **Стильные виджеты**: Обновленный аккуратный вид для виджетов домашнего экрана 4x1 и 4x2.

## 🛠️ Сборка из исходного кода

### Требования
* JDK 17
* Android SDK (API 34 / Build Tools 34.0.0)

### Сборка
```bash
# Клонирование репозитория
git clone https://github.com/anntr1k3/vlc-android-reborn.git
cd vlc-android-reborn

# Запуск юнит-тестов
./gradlew testDebugUnitTest

# Сборка готового Debug APK
./gradlew :application:app:assembleDebug
```

Собранный APK-файл будет находиться по пути:
`application/app/build/outputs/apk/debug/VLC-Android-3.7.1-debug-all.apk`

## 📂 Структура проекта

* `application/app` — Точка входа в приложение, манифест и сборка APK.
* `application/vlc-android` — Основной пользовательский интерфейс, фрагменты, плееры и ViewModel.
* `application/medialibrary` — Слой медиатеки и базы данных SQLite.
* `application/resources` — Общие ресурсы: темы, стили, иконки и локализации.
* `application/tools` — Вспомогательные утилиты, диспатчеры корутин и расширения.
* `application/television` — Интерфейс для Android TV.
